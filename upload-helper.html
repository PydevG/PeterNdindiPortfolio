How to use it

This helper is meant to keep the portfolio data in one place, so you do not end up with multiple JSON files serving the same gallery.

1
Select all images

Upload the full collection so the generated file reflects the complete portfolio.

2
Generate the dataset

The helper records title, filename, category, size, and relative image path automatically.

3
Replace the old source

Use the downloaded `data.json` as the single source of truth for the gallery page.

Keep just one active data source in the project. That makes future updates much easier to track and prevents missing work from split JSON files.
